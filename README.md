## ✈️ About The Project

**Wanderly** is a modern travel website designed to showcase destinations, travel packages, travel inspiration, and essential information in a clean and attractive interface.

The website focuses on a simple user experience with visually engaging destination cards, travel packages, feature sections, testimonials, and a responsive layout.

---

## 🌟 Features

* 🏠 Attractive Hero Section
* 🌍 Top Travel Destinations
* 🎒 Travel Packages
* 💡 Why Choose Us Section
* 📸 Travel Inspiration Gallery

* 🚀 Call-to-Action Section

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/Vashalika/Wanderly.git
```

### 2. Open the Project

Open the `Wanderly` folder in **VS Code** or any code editor.

### 3. Run the Website

Open:

```text
index.html
```

in your web browser.
